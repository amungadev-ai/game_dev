# First run — Expo SDK 58

From the repository root, use npm install, npm test, npm run typecheck, and npm start.
Use a matching Expo Go Android build (https://expo.dev/go). Connect phone and laptop to the same Wi-Fi. Scan the QR code. If LAN fails, try npm start -- --tunnel.
Expo recommends Node LTS. Node 24 LTS is preferred for this baseline. The existing Node 26 installation is not yet validated.
This is a minimal 2D interaction smoke test, not a finished expedition or 3D renderer. No VPS needed. The initial dependency lockfile will be captured following a successful install. Device validation remains pending.
